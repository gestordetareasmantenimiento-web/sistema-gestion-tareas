Plataforma Integral para la Gestión de Trabajos de Mantenimiento

🎯 ¿Qué es el Sistema de Gestión de Tareas?

Es una plataforma web integral diseñada para gestionar todo el ciclo de vida de las tareas de mantenimiento, desde su creación hasta su finalización. El sistema permite un control completo del flujo de trabajo, con roles específicos, aprobaciones escalonadas y seguimiento en tiempo real.

🔄 Flujo de Trabajo Completo

1

Creación de Tarea

El Inspector crea una nueva tarea especificando descripción, dirección, región y proveedor asignado. Se suben archivos adjuntos iniciales.

2

Asignación de WO

El Administrativo asigna un número de Work Order (WO) a la tarea, permitiendo su seguimiento oficial.

3

Certificación

El Proveedor ejecuta el trabajo y emite un certificado detallado con mano de obra, materiales y evidencia fotográfica.

4

Aprobación Inspector

El Inspector revisa y aprueba el certificado, pasando la tarea al siguiente nivel.

5

Aprobación Supervisor

El Supervisor realiza una revisión adicional y aprueba la tarea.

6

Aprobación Administrativa

El Administrativo aprueba a nivel administrativo y puede exportar materiales utilizados.

7

Aprobación Gerencial (Opcional)

Si se requiere, el Gerente aprueba tareas que necesitan autorización especial.

8

Aprobación Final CERCO

El CERCO realiza la aprobación final y marca la tarea como completada.

🚀 Cómo Empezar

Para Usuarios Nuevos:

  1. Acceso: Navega a http://localhost:5173
  2. Login: Usa las credenciales proporcionadas por tu administrador
  3. Dashboard: Explora tu dashboard personalizado según tu rol
  4. Primera Tarea: Si eres inspector, crea tu primera tarea de prueba
  5. Explorar: Familiarízate con las funciones disponibles para tu rol

Para Administradores:

  1. Configuración: Revisa la configuración de regiones y proveedores
  2. Usuarios: Gestiona usuarios y sus asignaciones regionales
  3. Monitoreo: Supervisa el flujo de tareas en tiempo real
  4. Reportes: Genera reportes de productividad y eficiencia
